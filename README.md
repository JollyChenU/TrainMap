# 铁路活动范围地图

根据始发城市、最早出发时间和最晚到达时间，计算铁路可达城市与车站，并在响应式地图中展示。

已接入 **GTFS 本地铁路快照 + 12306 按需经停核验**。查询不依赖余票，不保证实时开行，不包含同城异站接驳。驾驶范围不在本期范围内。

## 已实现

- 城市选择与城市内客运始发站多选筛选。
- 具体日期与每周固定时段，默认使用每周时段。
- G、D、C、K、T、Z、S、Y 及其他普速类型筛选。
- 直达与可配置的同站换乘。
- 运行日历、跨日时刻和分层最早到达路径计算。
- 城市、车站、行程详情及响应式矢量地图；支持城市/车站标记模式、名称显示挡位与密度阈值。
- 查询条件栏和地点列表可独立收起，地图支持页面内全屏。
- 在线基础地图，并在加载失败时保留简化地理轮廓。
- 后台刷新真实快照、进度显示、失败保留旧数据；同版本不重复下载。
- 仅在用户点击“手动刷新”时检查并下载新版本；初始化、城市切换和条件调整只读取本地快照。
- 最近 100 份结果持久化，支持恢复条件和结果。
- 对结果中的车次主动发起 12306 经停核验，不修改已计算结果。
- 单文件 HTML 和完全离线 ZIP 导出。
- 后端算法、API 与导出自动化测试。

## 运行

环境要求：

- Python 3.11 或更高版本。
- Node.js 22.12 或更高版本，推荐 LTS；启动脚本会构建前端。

在 PowerShell 中执行：

```powershell
.\start.ps1
```

也可以在资源管理器中双击 `start.cmd`，或在命令提示符中执行：

```bat
start.cmd
```

浏览器打开 `http://127.0.0.1:8023`。

脚本会创建 `.venv`、在缺少依赖时安装后端依赖和前端依赖，再构建并启动。沿用现有 pip 镜像配置，不覆盖包源。停止服务按 Ctrl+C。

数据库保存在 `backend/data/tarinmap.db`，可通过 `TARINMAP_DATABASE` 指定其他位置。首次打开空库时先使用内置演示快照；需要真实数据时由用户点击“手动刷新”，下载约 75 MB 的 GTFS 快照。准备期间显示进度，失败可重试。已准备的铁路数据可断网计算，但主页面 OpenStreetMap 底图仍需联网。

单进程运行，不要添加 `--workers`；快照互斥锁与任务去重目前不支持多进程。服务默认只监听本机；手机访问需在受信任局域网用 `--host 0.0.0.0` 启动并放行端口，不要直接暴露到公网。

## 数据与边界

- 主来源：[wensimehrp/chinese-railway-gtfs](https://github.com/wensimehrp/chinese-railway-gtfs)，铁路数据按上游 CC BY 4.0 声明保留署名，坐标来源 OpenStreetMap。
- 2026-11-15 实测版本 `gtfs-20261115-091021`：3,183 站、11,764 个有效车次；隔离 193 个时刻异常车次，261 站城市归属待核验。上游声明有效期为 2026-10-31 至 2027-02-02。
- 城市归属先匹配 12306 电报码，再匹配唯一精确站名，不按站名前缀猜测。待核验站点独立分组，所以页面显示“地点分组”，不将总数冒充行政城市数量。
- 每周时段会映射到下一次对应日期，统一北京时间；超出快照有效期会提示刷新或调整日期。最多查询 14 天。
- 候选包经过日历、站点引用、坐标和时刻校验后事务替换；异常车次超过 10% 拒绝更新。数据仍标为部分覆盖，不保证全国完整。
- 12306 核验为低频按需请求，至少间隔 5 秒；网络失败会显示原因，不影响缓存结果，不进行验证码或访问限制绕过。

## 导出

- **HTML**：直接内嵌正式 Vue 前端、当前查询条件和结果，版式及地图交互与主页面一致；无需后端，联网后由 OpenFreeMap 加载并更新底图。原查询开启中转时，导出文件同时保存“仅直达”和“包含中转”结果并可离线切换；未开启时只保存直达结果。刷新数据、重新计算、再次导出和 12306 核验在固化结果中不可用。
- **离线 ZIP**：解压后直接打开 `index.html`，无后端和网络依赖；含 `result.json`、清单及许可说明。底图为 Natural Earth 公共领域简化地理轮廓，支持缩放拖动，不含街道，也不表示真实铁路线路。
- 主页面继续使用原有 OpenStreetMap 在线底图；HTML 导出单独使用 OpenFreeMap 在线矢量底图，离线 ZIP 仍使用本地简化底图。

## 开发

后端：

```powershell
.\.venv\Scripts\python -m uvicorn backend.app.main:app --reload
```

前端：

```powershell
npm run dev --prefix frontend
```

Vite 开发服务器为 `http://127.0.0.1:5173`，并将 `/api` 代理到后端。

## 验证

```powershell
.\.venv\Scripts\python -m pip install -e ".[test]"
.\.venv\Scripts\python -m pytest
npm run build --prefix frontend
npm run test:e2e --prefix frontend
```

端到端测试要求本机安装 Microsoft Edge、8023 端口服务已启动且真实快照准备完成。测试使用本机 Edge，不额外下载浏览器；导出和调试产物写入系统临时目录。在线瓦片验收需要网络；离线导出测试会主动断网。
